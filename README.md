# 🔍 EVM Trace Support for Zed (`zed-trace`)

High-performance **EVM & Foundry trace navigator and language server** for [Zed](https://zed.dev). Turn raw, thousands-of-lines ASCII Solidity/Foundry execution traces (`.trace`, `.traces`, `.sol.trace`) into a beautifully highlighted, structured, and navigable call tree directly inside Zed editor.

---

## ⚡ Features

### 1. 🎨 Semantic Syntax Highlighting (XY-Zed & Solidity Theme Integration)
Trace files generated by Foundry/Forge (`forge test -vvvv`, `forge script -vvvv`, `cast run`) are not raw Solidity code—they contain dynamic ASCII tree characters (`├─ `, `│  `, `└─ `), gas metrics, storage changes, and execution results. Standard Tree-sitter parsers treat these files as syntax errors.

`zed-trace` provides context-aware **LSP Semantic Tokens (`textDocument/semanticTokens/full`)** that cleanly tokenize every element of the trace file and match the **[XY-Zed](https://github.com/zarifpour/xy-zed)** theme and standard Solidity coloring:

| Element | Semantic Scope | XY-Zed Color | Trace Examples |
| :--- | :--- | :--- | :--- |
| **Keywords & Modifiers** | `keyword` / `modifier` | **Purple / Magenta** (`#c678dd`) | `emit`, `new`, `storage`, `changes`, `[staticcall]`, `[delegatecall]`, `[Return]`, `[Stop]`, `[Revert]` |
| **Contracts & Types** | `type` | **Cyan / Teal** (`#08e7c5`) | `CCCTest`, `Proof`, `VM`, `WBNB`, `IPancakeRouter`, `FlashLoan`, `Transfer`, `Sync`, `uint256`, `address`, `bytes` |
| **Functions & Selectors** | `function` | **Yellow / Gold** (`#DCDCAA`) | `setUp`, `test_profit_success`, `run`, `balanceOf`, `flashLoan`, `transfer`, `getAmountsOut`, `getReserves`, `sync`, `withdraw`, `buy`, `sell` |
| **Gas & Wei Values** | `number` | **Light Olive / Green** (`#B4CDA8`) | `[14739827]`, `416831487011304318246517`, `[4.168e23]`, `1e18`, `0` |
| **Hex Addresses & Slots** | `property` | **Light Cyan / Blue** (`#9cdcfe`) | `0xbb4CdB9CBd36B01bD1cBaEBF2De08d9173bc095c`, `0x7476b743a16e0315bdd...` |
| **Parameters & Labels** | `variable` | **Sky Blue** (`#7cc6f8`) | `from:`, `to:`, `amount:`, `param0:`, `owner:`, `spender:`, `SENDER`, `OTHER_CALLER` |
| **Booleans** | `keyword` / `boolean` | **Green / Purple** (`#22c942`) | `true`, `false` |
| **String Literals** | `string` | **Warm Orange** (`#CD9069`) | `"bsc"`, `"SENDER "` |
| **Arrows & Delimiters** | `operator` | **Bright Yellow** (`#ffd866`) | `::`, `→`, `←`, `@`, `:`, `,` |
| **Tree Branch Guides** | `comment` | **Forest Green / Dim** (`#6A9955`) | `├─`, `└─`, `│` |

### 2. 🌳 Hierarchical Symbol Navigator (Zed Buffer Symbols & Outline Panel)
- Parses ASCII tree branches into structured parent-child call trees.
- Populates Zed's native **Buffer Symbols modal** (`ctrl-shift-o` / `cmd-shift-o`) and **Outline sidebar panel** (`ctrl-shift-b` / `cmd-shift-b`).
- Instant keyboard navigation: fuzzy-search and jump directly to any sub-call (e.g. `flashLoan`, `swap`, `buy`, `sync`, or `withdraw`) in massive trace files.
- Visual symbol categories with native Zed icons:
  - 🔷 **Root Test Call**: `CCCTest::setUp()`, `CCCTest::test_profit_success()`
  - ⚙️ **Contract Call**: `Proof::run()`, `0xbb4C...::balanceOf() [staticcall]`
  - 🏗️ **Contract Creation**: `new Proof@0x3255...`
  - 📢 **Event Emission**: `emit FlashLoan(...)`, `emit Transfer(...)`
  - 📦 **State / Storage**: `storage changes`

```text
▼ CCCTest::test_profit_success() [14.74M gas]
  ├─ 0xbb4C...::balanceOf [2.5k gas] [staticcall]
  ├─ VM::prank [0 gas]
  ▼ Proof::run [14.72M gas]
    ├─ 0xbb4C...::balanceOf [2.5k gas] [staticcall]
    ▼ 0x8F73...::flashLoan [14.66M gas]
      ▼ 0x9321...::flashLoan [14.65M gas] [delegatecall]
        ├─ emit FlashLoan(param0: Proof: [0x3255...], ...)
        ▼ 0xbb4C...::transfer [28.0k gas]
          ├─ emit Transfer(...)
          ▼ storage changes
            ├─ @ 0x7476...: 0x... → 0
            └─ @ 0x086b...: 0 → 0x...
        ▼ Proof::onMoolahFlashLoan [14.61M gas]
          ▼ 0x10ED...::getAmountsOut [9.7k gas] [staticcall]
```

---

### 3. 📂 Deep Code Folding (`textDocument/foldingRange`)
- Automatically generates folding ranges for every nested execution branch.
- Click gutter fold arrows or use `ctrl-alt-{` / `ctrl-alt-}` (`cmd-alt-{` / `cmd-alt-}`) to collapse thousands of lines of sub-calls in a single keystroke.
- Folds storage change blocks and sub-traces cleanly.

---

### 4. 💡 Rich Hover Analysis (`textDocument/hover`)
- **Gas Metrics**: Formats raw gas into readable metrics (e.g., `14,716,127 gas (~14.72M)`).
- **Address Labels**: Resolves contract names (e.g., `WBNB`, `PancakeRouter`, `ListaDAO`) and labels registered via `VM::label`.
- **Value & Parameters**: Decodes wei amounts into formatted token units.

---

### 5. 🌐 Interactive Phalcon-Style Web Viewer (`trace-lsp web`)
Built-in command to export or view any `.trace` file in a browser with a **Phalcon Explorer** invocation flow interface (collapsible nodes, search filter, and toggle pills for Static Call, Storage Changes, and Events).

```bash
trace-lsp web sample.trace
# Generates sample_explorer.html
```

## 🚀 Getting Started

### 1. Install `trace-lsp`
```bash
cargo install --path crates/trace-lsp
```
Verify the installation:
```bash
trace-lsp --version
```

### 2. Configure Zed Settings (`~/.config/zed/settings.json`)
Add the following to your Zed settings:

```json
{
  "languages": {
    "EVM Trace": {
      "language_servers": [
        "trace-lsp"
      ],
      "document_symbols": "on",
      "semantic_tokens": "full"
    }
  },
  "file_types": {
    "EVM Trace": [
      "trace",
      "traces",
      "sol.trace"
    ]
  },
  "lsp": {
    "trace-lsp": {
      "binary": {
        "path": "/home/sean/.cargo/bin/trace-lsp",
        "arguments": [
          "--stdio"
        ]
      }
    }
  }
}
```

### 3. Install the Extension in Zed
1. In Zed, open the command palette (`ctrl-shift-p` / `cmd-shift-p`).
2. Run `zed: install dev extension`.
3. Select this repository folder (`zed-trace`).

### 4. Open a Trace File
Open [`sample.trace`](sample.trace) or any Foundry trace file in Zed:
- Press `ctrl-shift-o` (or `cmd-shift-o`) to open the **Buffer Symbols** modal.
- Press `ctrl-shift-b` (or `cmd-shift-b`) to toggle the **Outline Panel**.
- Use `ctrl-alt-{` and `ctrl-alt-}` to fold and unfold call branches.
- Hover over any call, address, or gas number to view detailed analysis.
